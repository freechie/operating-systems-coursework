# Operating Systems Coursework

This repository collects source-code exercises and selected submitted material
from an operating systems course.

## Contents

- `HW1`: C programs using processes and pipes
- `HW2`: CPU scheduling implementations in C and Java, supporting build files,
  the submitted PDF, and retained supplied-source copies
- `HW3`: Producer-consumer and page-offset C programs
- `HW4`: Virtual-memory-manager C program

Original source filenames have been preserved. The retained HW2 course and
supplied materials require a redistribution decision before this repository is
published. Compiled binaries, object files, archives, screenshots, textbook
files, and lecture materials are intentionally excluded.
